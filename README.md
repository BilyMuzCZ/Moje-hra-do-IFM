# Moje-hra-do-IFM

Tuhle hru jsem vytvářel během hodin IFM ve škole a cca 1,5 hodiny mimo školu.

Nechoď spát (rok 729)
Textová středověká adventura, ve které se probouzíš během temné noci, tvoje rodina je pryč a hrad v dálce čelí nečekanému útoku. Tvoje rozhodnutí rozhodnou o tom, zda přežiješ, zachráníš krále, nebo zemřeš potupnou smrtí.

Ve hře je několik klíčových rozhodnutích, které změní významné momenty vašeho playtrough, také tam jsou rozhodnutí, která nezmění nic.
Ve hře je jednoduchý inventářový systém, který změní některé části příběhu.

Tobiáš Caha, 1.B
